## ✨ [View Design Prototype in Figma →](https://www.figma.com/design/Z7xqv9mjPvsmjpUS3ZEPUv/Cozy-App?node-id=0-1&t=MlOr3DQYdeEZam6D-1)

**Cozy Feelings** is a minimal, warm, and safe space designed for emotional well-being. Built with **Flutter**, this application focuses on simplicity to help users track their daily moods and thoughts without the clutter of traditional journals. It’s about checking in with yourself in a cozy and calm environment.

## 🚀 Key Features

- **Daily Mood Tracking:** A simple interface to log how you feel using intuitive and friendly icons.
- **Thought Dumping:** An open space to write whatever is on your mind—no judgment, just emotional release.
- **Mood History:** A visual history to review your emotional journey and entries over time.
- **Calendar View:** A monthly calendar grid to inspect moods and entries recorded on specific dates.
- **Multi-theme Support:** 6 carefully selected cozy color palettes to personalize the app's look and feel.
- **Cloud Backup & Sync:** Google Drive integration and local file export/import to keep reflections safe.
- **Context Tags:** Add and manage context tags with drag-and-drop reordering.
- **Search & Filters:** Real-time text search and interactive filters by date range, emotion, and tags.
- **Privacy Lock:** Optional 4-digit PIN protection with automatic locking when the app is minimized.
- **Emotional Insights & Streaks:** Dedicated statistics tracking daily check-in streaks, dominant moods, and emotional balance.
- **Cozy UI/UX:** A carefully selected color palette and smooth animations designed to reduce anxiety.
- **Privacy Focused:** Personal reflection remains secure and managed with privacy in mind.

## 🎨 UI/UX Design
The interface was meticulously planned and designed in **Figma**, focusing on soft aesthetics (pastel colors) and a clean layout to ensure a relaxing user experience. You can explore the full prototype in the link above.

## ⚙️ Development Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/nar-ran/cozy_feels_app.git
   cd cozy_feels_app
   ```

2. **Install dependencies:**
   ```bash
   flutter pub get
   ```

3. **Generate localization files:**
   ```bash
   flutter gen-l10n
   ```

4. **Run tests:**
   ```bash
   flutter test
   ```

5. **Run the app:**
   ```bash
   flutter run
   ```
